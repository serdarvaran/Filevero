# Filevero for Windows

Mac and Windows share the 50-format / 29-tool catalog and aligned Home, Library, paste, preview and window-management workflows. See [the feature parity and verification matrix](FEATURE-PARITY.md) for implementation, evidence and platform differences.

Filevero uses WPF / .NET 10, the Filevero mark, a file garden, rounded cards and a light/dark palette, with Windows keyboard conventions and native window controls. Build with `dotnet publish windows/Filevero.Windows -c Release -o build/windows/Filevero`. The output is self-contained; users do not install .NET separately. Keep the portable folder together in a writable location so updates can replace it safely.

The shared catalog contains 29 tools and 50 input formats. It includes photo editing, framing/collages, crop/annotation/redaction, QR/PDF tools, document/Pages/EPUB/spreadsheet/slides conversion, archives/subtitles, media tools and public web downloads. Runtime setup is available from Home. Remove Background downloads the ISNet model (~179 MB, Apache-2.0) on first use and runs it on the PC with ONNX Runtime. Download URLs and SHA-256 hashes are pinned in `Toolchain.cs`, `OfficeRuntime.cs` and `MetadataService.cs`; upstream licenses remain separate from Filevero's MIT license. See [third-party notices](THIRD-PARTY-NOTICES.txt).

Library and preferences live in `%LOCALAPPDATA%/Filevero`, outside the portable application folder. Library keeps the last 50 successful exports and clipboard imports. Text imports use UTF-8 and image imports use lossless PNG. Clipboard history is off by default. When it is turned on in Settings → Clipboard, Filevero keeps copies in `%LOCALAPPDATA%/Filevero/Clipboard`, skips content that apps exclude from clipboard history and copies made in the excluded apps (password managers by default), and opens the picker with **Ctrl+Shift+Alt+V**. In the picker, **Enter** pastes, **Shift+Enter** pastes plain text, **Ctrl+1–9** pastes a row, **Ctrl+P** pins, **Ctrl+O** opens in Filevero, **Ctrl+T** opens actions (case changes, tidy whitespace, JSON formatting, QR code, save image as PNG/JPG) and **Ctrl+Delete** deletes an unpinned item; pressing the shortcut again closes it. Saved workflows (Settings → Workflows) convert, fit, compress and clean files in order and appear on Home when files are selected; Settings → Watched folders runs a workflow on new files in a folder and saves results in its `Filevero` subfolder. Prepare to Share removes metadata, turns HEIC and other photos into JPG and fits large images within 2048 px. Signed public update staging verifies the manifest, archive hash, version and trusted signature before restart.

While dragging in Explorer or another application, **Ctrl** opens tools, **Shift** conversion and **Alt** file actions. Settings can change the three chords. **Ctrl+Shift+D** opens a copied public media link. The app can remain in the system tray.

**Ctrl+O** chooses files; **Ctrl+V** imports files/text/images/links outside text fields; **Ctrl+1/2** switches Home/Library; **Ctrl+F** searches; **Ctrl+U** checks updates. **Ctrl+Space** opens the selected files' wheel; choose **Convert** to select an output format. Arrows/Tab choose an item, Enter opens it and Escape closes it. In the Home file list, **Delete** removes the selected entries from Filevero without deleting the original files.

Media editors use **Space** for play/pause, **Left/Right** for one-second seeking, **Shift+Left/Right** for frame steps, **I/O** for range marks and **Shift+Space** to play the selected range. Crop supports drag, Shift ratio lock, selection move/resize, aspect presets and Enter save. Annotation supports Select/Move, Delete and Ctrl+Z. Normal text-field editing is preserved.

`Filevero.Verify` checks the shared engine and security foundation. `Filevero --smoke-test` runs real Windows keyboard, clipboard, OLE drag, Library, editor and export checks and writes diagnostic JSON/PNG artifacts. See [verification details](FEATURE-PARITY.md#commands-and-evidence) before interpreting a CI artifact as a completed test or official release.
